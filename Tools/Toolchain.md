Paths in reproduction instructions point to the grouped tools; audio generation and localization retain their original cross-script calls.

`python Tools/Maintenance/audit_project.py` performs a read-only check of source size, duplicate Unity GUIDs, missing meta files, Python syntax and documented tool paths. Unity's **Last Light → Maintenance → Audit asset usage** produces `Logs/AssetUsage.json` with conservative scene/prefab/material/Resources roots and transitive dependencies. Unreachable assets still need Blender, dynamic-load and provenance review; this tool never deletes them automatically. Source archives, editable Blender inputs, licenses, current build, verification tools and user probe scripts are retained. Blender automatic backups and Python bytecode are ignored by Git.
